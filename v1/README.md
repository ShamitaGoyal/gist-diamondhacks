# Chrome Extension Side Panel (v1)

This is a code bundle for Chrome Extension Side Panel. The original project is available at https://www.figma.com/design/nMAzT6FU8lGimb9EGnk6OA/Chrome-Extension-Side-Panel.

## Running the code

From this directory:

```bash
pnpm install
pnpm run dev
```

API + Vite together:

```bash
pnpm run dev:full
```

Set `GEMINI_API_KEY` in `.env.local` (see `.env.example`).
